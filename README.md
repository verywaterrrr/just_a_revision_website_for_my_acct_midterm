# ACCT2010 midterm revision

Self-contained static revision website with eight lessons, 39 written recall questions, worked examples, a guide coverage map and a reference sheet.

Study: https://verywaterrrr.github.io/just_a_revision_website_for_my_acct_midterm/

The course covers Chapters 1, 2, 3, 4, 6 and 7 of the supplied ACCT2010 midterm material. Source-document titles and page references are preserved in `sources.html`. Original course PDFs and private learning records are not included. This is an independent study resource, not an official HKUST publication.

Open `index.html` locally or serve this folder with `python3 -m http.server 8000`. No package installation or build step is required. Shared CSS, native answer disclosures and scratch boxes work without external assets. Scratch answers do not persist after closing or reloading a page.

GitHub Pages publishes the `main` branch root.
